# ADP Acquisition Intelligence Platform — Phase 1 Documentation

This repository is the canonical planning layer for Phase 1 of the ADP Acquisition Intelligence Platform. It contains specifications only; production application code belongs in a separate implementation repository or a later top-level `apps/` and `packages/` tree.

Start with [docs/README.md](docs/README.md). Implementers must treat the functional specification, technical architecture, implementation constitution, architecture review checklist, roadmap, and exit contract as a coordinated source of truth.

Phase 1 implements the loop:

`Collect → Normalize → Evidence → Confidence → Completeness → Score → Review → Discover → Re-score → Outreach → Opportunity → Learn`

Referral partners, referral agreements, introduction graphs, and partner-health workflows begin in Phase 2.
